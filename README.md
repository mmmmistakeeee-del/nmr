## 不確かさと警告を読む

- **課題1**　実測の周波数列を固定し、独立な加法雑音と相関する振幅揺らぎを加えた模擬波形を300組作った。標準不確かさは再推定値の標本標準偏差で、共鳴周波数では21.45 Hz。元波形の採用解は変調幅ゼロだが、模擬波形の再フィットでは変調幅も動かした。線幅の分布の偏りは[分布図](07_補足解析/課題1_共鳴信号/解析I/20261020_KITtest01_uncertainty_distributions.png)と[各試行の値](06_入力/課題1_共鳴信号/解析I/20261020_KITtest01_uncertainty_samples.csv)で確認できる。
- **周波数の保存刻み**　第2.6節の約0.7 Hzは、10 Hz刻みの保存値に各点独立な一様乱数（±5 Hz）を加えた感度確認。元の実行スクリプトを特定できなかったため、記録された条件で[再現用コード](05_解析コード/check_frequency_rounding.py)を追加した。300回で0.687 Hz（当時の記録は0.686 Hz）、全点を一律に+5 Hzとした対照で+5.00 Hzだった。
- **課題2・3**　各波形の残差を中心化し、自由度補正を掛け、連続する5〜7点ごとに符号を無作為に反転した。各波形120回の再フィットで得た標本標準偏差が誤差棒に対応する。[詳細CSV](04_解析結果/Voigt推定値と不確かさ.csv)の `_sd` が標準偏差、`_p16`・`_p84` が16・84百分位。日をまたぐずれや装置の校正を含む絶対精度は別途評価が必要。
- **図2・3の外輪、図4・6の三角**　採用モデルのフィットに注意が付いた点。対象は課題2で35/78座標、課題3で9/27条件。各条件の理由は[注意を要する波形](04_解析結果/注意を要する波形.csv)の `fit_notes` 欄、120・180・240 Hzで見られた背景構造は `observation` 欄にある。定量比較から外した点は[参考点と除外点](04_解析結果/参考点と除外点.csv)で識別できる。

| 警告 | コードでの判定 |
| --- | --- |
| 残差相関 | 測定順で隣り合う残差の相関係数の絶対値が0.30を超える。課題2で22座標、課題3で4条件 |
| 弱信号 | 背景を引いた山谷差の半分を、自由度補正後の残差標準偏差で割った値が5未満 |
| 背景範囲不足 | 推定中心から近い方の掃引端までの距離が、変調前の吸収線半値全幅より短い |
| 幅の不確かさ大 | 吸収線半値全幅の標準不確かさが推定値の25%以上 |
| 形状量が下限 | ローレンツ半値半幅が0.0201 kHz以下、ガウス幅が0.0401 kHz以下、または課題3の変調片振幅が0.0011 kHz以下 |

判定は[残差の診断コード](05_解析コード/adopted_diagnostics.py)と[図表を作るコード](05_解析コード/voigt_figure_pack.py)の `fit_flag_text` で確認できる。警告は重複する。課題2の測定日差の平均+9.675 kHzは、表2の4座標で観測した値であり、図2の全座標には一律補正を加えていない。課題3の線幅は有限変調モデルに依存し、固有の横緩和時間を一意に決められない。

## 再現する

PowerShellでこの `NMR!` フォルダを開く。Python、NumPy、SciPy、pandas、Matplotlibを使用する。保存した数値を使って図表集を再生成するには次を実行する。

```powershell
python -B 05_解析コード/reproduce.py
```

集計図6点・結果CSV7表・図表集PDFが `作業用/図表` に出る。課題1の集計図には保存済み画像を用いる。測定波形から4モデル比較と課題2・3の再推定まで行うには `--refit` を付ける。条件を変える場合は `作業用/再フィット` の既存キャッシュがない作業コピーを使う。

| 再現したいもの | `NMR!` 直下からのコマンド | 出力先 |
| --- | --- | --- |
| 採用106波形の個別図 | `python -B 05_解析コード/plot_adopted_fits.py` | `03_図表/個別フィット` のPNGと索引を更新 |
| 課題1の300回分の保存値から分布図・集計表を再作成 | `python -B 06_入力/課題1_共鳴信号/解析I/nmr_uncertainty.py --summarize-only` | 同じ解析Iフォルダに出力。全再推定にはオプションを外す |
| 表2と測定日比較図 | `python -B 07_補足解析/課題2_位置依存/解析II/compare_measurement_dates.py` | 同じ解析IIの `results_date_comparison` を更新 |
| 周波数の保存刻みの感度 | `python -B 05_解析コード/check_frequency_rounding.py` | 標準偏差と一律シフトの結果を画面に表示 |

保存値からの再生成は別の作業コピーで確認した。採用した主解析の計算コードは[コード案内](05_解析コード/README.md)、元の測定波形と採用済み係数は[入力](06_入力/)にある。補足解析には採用前の波形・参考条件・過去版も含む。本文の数値を引用するときは上の図表対応表を使う。
